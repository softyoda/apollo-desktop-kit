# Moonlight scripts

Installation client, profils, lancement quotidien et placement des fenêtres Moonlight.

- `windows/` : scripts Windows et construction de `Apollo-Setup.cmd`.
- `linux/` : lanceur multi-écrans Linux.

Les anciens points d'entrée `windows/` et `linux/` à la racine restent des adaptateurs de compatibilité. Les helpers natifs communs restent dans `lib/`.

Voir [Windows](../../docs/windows-client.md) et [Linux](../../docs/linux-client.md).
