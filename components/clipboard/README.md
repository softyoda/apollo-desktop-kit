# Clipboard

Intégration CrossPaste indépendante du transport vidéo et de SpaceMouse Link.

- `windows/Clipboard.ps1` : détection du Store, installation et préférences CrossPaste.
- `windows/Allow-ClipboardNetwork.ps1` : configuration réseau existante.
- `linux/setup_crosspaste.py` : installation Linux.

Voir [le guide presse-papiers](../../docs/clipboard.md). SpaceMouse Link ne lit ni ne synchronise le presse-papiers en arrière-plan ; ses boutons Copier/Coller servent uniquement à l'invitation d'appairage.
